# Company ERP v0.1.0

Company ERP v0.1.0 是第一个可用于 NAS 内网试运行的 MVP 基础版本。

## 已包含

- React/Vite Web 工作台和 Fastify API。
- PostgreSQL + Prisma migration。
- 固定角色、登录 session、API 权限边界和项目点数据级过滤。
- 往来方、物料、仓库、人员权限、项目点、外部项目点账号、厨房设备基础台账。
- 采购需求、采购记录、入库、库存流水、当前库存余额、补货建议。
- 项目点领用申请、总部出库、计费/耗材快照。
- 合同台账、合同附件路径、合同形态和标的分类。
- 证照资质台账、Excel 导入批次、DEMO 清理和账号密码重置运维脚本。
- NAS Docker 部署、备份/恢复脚本、部署版本信息接口和系统设置页版本展示。

## 部署方式

默认部署到公司 NAS 内网：

- Web 通过 NAS 内网端口访问。
- API 通过 Web/Nginx 同源反代访问。
- PostgreSQL 和附件目录挂载到 NAS 持久化目录。
- 部署版本通过 `/api/app-version`、`/health`、`.deploy-revision.json` 和 `docker compose ps` 共同确认。

## 不包含

- 公网暴露、HTTPS、外部域名、SSO、2FA。
- 真实财务应收应付、薪资、OCR、微信自动解析、移动端 App。
- 真实业务数据、真实 `.env`、NAS 凭据、数据库备份、附件或扫描件。
- NAS 验收默认不写入 DEMO/TRIAL/smoke 测试数据。

## 验证要求

发布前必须通过：

- `db:generate`
- `db:validate`
- `typecheck`
- `test`
- `build`
- Web E2E
- `git diff --check`
- 敏感信息扫描

每次 push 前都必须执行 goal-mode bug sweep，不允许把已知失败测试、运行时错误、权限绕过或敏感信息推送到 GitHub。
