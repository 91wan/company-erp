# Module Plans

This directory stores confirmed module plans before implementation.

Required MVP module plans:

- `people-permissions.md` - created
- `materials-suppliers.md`
- `contracts.md` - created
- `purchase-requests.md` - created
- `receiving-inventory.md` - created
- `project-site-usage.md` - created
- `excel-import.md`

The existing files under `docs/chat-prompts/` are prompts for producing plans, not final module plans.
