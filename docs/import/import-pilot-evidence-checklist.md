# Excel 导入试点证据清单

本清单用于 NAS 内网试点前保存可复核证据。证据可使用脱敏数据或少量受控真实数据，不要求提交真实敏感数据、合同原文、健康证图片或 NAS 附件原文。

| 证据项 | 要求 | 阻断 NAS 试点 |
| --- | --- | --- |
| `npm run ops -- trial-ready` 输出 | 保存完整命令输出，确认最终无失败。 | 是 |
| `npm run ops -- import-pilot-check` 输出 | 显示 `NAS 试点导入前置检查` 且全部通过。 | 是 |
| `npm run ops -- import-pilot-smoke` 输出 | 显示 `导入试点 smoke 通过`。 | 是 |
| 模板包下载文件名 | 记录下载的模板包或单模板文件名。 | 是 |
| health_certificates 预检截图 | 截图需显示健康证归属类型、姓名、到期日期，不出现身份证后四位、健康证编号、发证机关。 | 是 |
| `error-report.xlsx` | 保存一份可读错误报告，包含“问题行”和“导入说明”sheet。 | 是 |
| confirm 后批次详情截图 | 显示批次状态、导入统计和不能撤销提示，截图需脱敏。 | 是 |
| 试点复核 tab 截图 | 显示合同、健康证、项目点合规、库存、错误/警告复核任务。 | 是 |
| 证照健康证页面截图 | 能看到导入后的健康证到期提醒。 | 是 |
| 项目点风险台账截图 | 能看到项目点合规风险或正常状态变化。 | 是 |
| 库存流水截图 | 能看到期初库存产生的 opening 库存流水。 | 是 |
| 审计日志截图或导出 | 能查到 `import_job.preview` / `import_job.confirm`。 | 是 |

建议项：保存操作者、试点日期、deploy revision、使用的数据范围和是否为脱敏数据。
