# Excel 导入模块停止线

本阶段导入模块的目标是支撑 NAS 内网试点的数据初始化、到期提醒和导入后复核，不继续无边界扩展成附件识别或批量迁移系统。

## 本阶段不做

1. 不做 OCR 或图片自动识别。
2. 自动识别健康证图片内容。
3. ZIP 图片批量入库。
4. 合同 PDF 扫描件批量上传。
5. 导入一键回滚或自动 rollback。
6. 覆盖式更新导入。
7. 外部项目点账号自助全局导入。
8. 用户手填 Storage Key。

## 下一阶段再评估

1. Excel + ZIP 图片配对。
2. 合同 PDF 扫描件批量登记。
3. 导入撤销或回滚。
4. 更新导入模板。
5. 附件批量校验。

## 试点边界

试点前必须运行 `npm run ops -- import-pilot-check` 和 `npm run ops -- import-pilot-smoke`。导错后不要直接删数据库，应到对应业务模块作废、停用或修正。
