# Excel 数据导入 — 试点操作手册

> 适用范围：首次使用 Excel 导入功能的运营人员  
> 前置条件：已有系统账号，角色为"数据管理员"或更高权限

---

## 概览

Excel 导入分三步：**下载模板 → 预检 → 确认写入**。  
系统不会在预检阶段写入任何数据，只有点击"确认导入"后才真正入库。

---

## 第一步：下载并填写模板

1. 进入 **数据初始化 → Excel 导入**
2. 在"导入预检"标签页，选择模板类型（如"供应商"、"物料"、"项目点现场人员"等）
3. 点击"**下载当前模板**"获取对应 xlsx 文件，或"**下载全部模板包**"一次下载所有模板
4. 按表头说明填写数据，注意：
   - 第 1 行为表头，**不可删除或修改列名**
   - 数据从第 2 行开始
   - 带 `*` 标注的字段为必填

### 健康证模板特别说明

| 字段 | 说明 |
|------|------|
| 健康证归属类型 | 填写"项目点健康证"或"公司健康证" |
| 项目点编码 | 归属类型为"项目点健康证"时必填 |
| 员工编码 | 归属类型为"公司健康证"时必填 |
| 姓名 | 必填。若项目点内有同名人员，需同时填写手机号以消歧义 |
| 手机号 | 可选，同名人员存在时必填 |
| 到期日期 | 格式：YYYY-MM-DD |
| 图片文件名 | 可选，不强制上传图片 |

---

## 第二步：上传文件并预检

1. 在"导入预检"标签页选择已填好的 xlsx 文件
2. 点击"**导入预检**"
3. 系统自动切换到"行级预览"标签页，显示每一行的检验结果
4. 检查预检结果：
   - ✅ 绿色"可导入"：该行无问题，将写入
   - ⚠️ 黄色"有警告"：可以写入，但存在注意事项（如空白图片）
   - 🔵 蓝色"已跳过"：编码已存在，系统将跳过该行（不覆盖已有记录）
   - ❌ 红色"有错误"：该行有问题，**必须修正后重新预检才能导入**

5. 如有错误行，点击"**下载错误行**"查看详细错误，修正后重新上传预检

---

## 第三步：确认导入

1. 确认所有行状态均为"可导入"、"有警告"或"已跳过"（无红色错误行）
2. 查看顶部摘要卡片，确认写入行数符合预期
3. 点击"**确认导入**"按钮
4. 系统完成写入后，可在"导入批次"标签页看到状态变为"已确认导入"

> ⚠️ 导入为**追加写入**，不覆盖已有记录。已存在编码的行会被跳过。

---

## 常见问题

**Q: 预检通过但确认导入后找不到数据？**  
A: 请到对应模块（如供应商台账、物料台账）搜索查看。导入的记录会立即可查。

**Q: 提示"同一项目点存在同名在场人员"？**  
A: 健康证导入依赖"项目点现场人员台账"中的人员信息。若同名，请在手机号列补充手机号区分，或先在人员台账中添加备注区分。

**Q: 图片是否必须上传？**  
A: 不强制。图片文件名可为空。如需后续关联图片，可在健康证管理中单独上传。

**Q: 导入后能否撤销？**  
A: 暂不支持撤销。如需删除错误导入的数据，请联系系统管理员。
