# NAS 试点数据导入演练

> 适用场景：首次在 NAS 上线时，用 1 个试点项目点完成全量基础数据初始化导入  
> 前置条件：系统已部署，有"数据管理员"角色账号

---

## 导入限制（全局）

- **不做 OCR** — 图片识别不在系统范围内
- **不强制健康证图片** — 图片文件名可为空，后续单独上传
- **不强制合同 PDF** — 合同附件可后续单独上传
- **默认仓库** — 期初库存使用无锡总部仓库（仓库编码见物料模板说明）

---

## 推荐导入顺序

按依赖关系由浅到深：

| 顺序 | 模板类型 | 原因 |
|------|---------|------|
| 1 | 往来方 / 供应商 | 合同需引用往来方 |
| 2 | 部门与员工 | 项目点现场人员依赖员工台账 |
| 3 | 项目点 | 项目点现场人员、健康证依赖项目点 |
| 4 | 项目点现场人员 | 健康证导入依赖人员台账 |
| 5 | 健康证 | 依赖项目点和现场人员 |
| 6 | 合同 | 依赖往来方 |
| 7 | 物料 | 期初库存依赖物料 |
| 8 | 期初库存 | 最后导入，依赖仓库和物料 |

---

## 每步操作说明

### 步骤 1：往来方

1. 进入 **Excel 导入 › 导入预检**，模板选"往来方/供应商"
2. 下载模板，填写供应商/客户/分包主体信息
3. 上传预检，确认无红色错误后点击"确认导入"
4. **复核**：跳转到 **基础资料 › 往来方** 核查记录数量和内容

### 步骤 2：部门与员工

1. 模板选"部门与员工"
2. 先填部门，再填员工（员工行引用部门编码）
3. 预检、确认导入
4. **复核**：跳转到 **人员权限 › 公司员工** 和 **部门**

### 步骤 3：项目点

1. 模板选"项目点"
2. 填写项目点编码、名称、服务模式
3. 预检、确认导入
4. **复核**：跳转到 **项目点 › 风险台账**

### 步骤 4：项目点现场人员

1. 模板选"项目点现场人员"
2. 项目点编码须与步骤 3 中一致
3. 预检、确认导入
4. **复核**：跳转到 **项目点 › 资料审核 › 对应项目点**，查看项目点现场人员记录

### 步骤 5：健康证

1. 模板选"健康证到期"
2. 健康证归属类型填"项目点健康证"或"公司健康证"
3. 图片文件名可留空（不强制上传图片）
4. 预检、确认导入
5. **复核**：跳转到 **证照资质 › 健康证**，核查到期状态
6. 如有项目点健康证，**项目点 › 风险台账** 的合规状态也会同步更新

### 步骤 6：合同

1. 模板选"合同到期提醒"
2. 合同对方主体名称须与步骤 1 中往来方名称一致
3. 预检、确认导入
4. **复核**：跳转到 **合同 › 合同风险**，检查到期提醒是否正确

### 步骤 7：物料

1. 模板选"物料"
2. 默认供应商编码须与步骤 1 中往来方编码一致
3. 预检、确认导入
4. **复核**：跳转到 **基础资料 › 物料**

### 步骤 8：期初库存

1. 模板选"期初库存"
2. 仓库使用无锡总部仓库（默认仓库编码见模板说明行）
3. 物料编码须与步骤 7 中一致
4. 预检、确认导入
5. **复核**：跳转到 **库存 › 当前库存** 核查余额

## 如何下载错误报告

1. 预检后如有红色错误行，点击"行级预览"标签页顶部的"下载错误行"
2. 也可在"导入批次台账"中点击对应批次的"错误报告"链接
3. 打开 xlsx 文件，有两个 sheet：

   | Sheet | 内容 |
   |-------|------|
   | **问题行** | 含"行号"、"问题"、"建议处理"列；每行只保留原始字段，敏感字段（如密码、令牌）已屏蔽 |
   | **导入说明** | 批次汇总信息：批次 ID、模板类型、文件名、预检时间、总行/可导入/警告/错误/跳过行数 |

4. 根据"问题"列的错误提示，修正 Excel 对应行
5. 修正后重新上传预检，直到无红色错误

---

## 如何确认 warning 行

1. 黄色警告行仍可导入，但需人工确认
2. 预检后"确认导入"按钮旁会提示"含警告 N 行"
3. 确认后警告行会写入，请在对应模块人工复核数据

---

## 如何查看导入结果

1. 确认导入后，"行级预览"标签页自动添加"导入结果"列
2. 每行显示目标记录所属模块（如"往来方台账"、"健康证台账"）
3. 点击"查看证照 / 查看合同 / 查看库存流水"等按钮直接跳转到目标模块，导入行会尽量带上目标分区和记录 ID

### 跳转后记录不可见怎么办

若点击"查看"后系统提示"已跳转…但记录不可见或无权限，请搜索该记录"，可能原因：

- 当前账号没有该记录所属项目点/组织的查看权限
- 记录已被软删除或停用
- 跳转时该记录未在当前筛选条件下显示

处理方法：清除搜索条件后手动搜索对应编码；或联系管理员确认权限范围。

## NAS 试点前最后检查清单

1. `npm run import:pilot-check` 通过。
2. Excel 导入模板包可下载。
3. 试导入 1 个项目点。
4. 试导入项目点现场人员。
5. 试导入 2 条健康证。
6. 健康证能在证照模块看到。
7. 项目点合规 summary 有变化。
8. 错误报告可下载并可读。
9. 导入结果“查看”能跳到对应模块和分区。
10. 审计日志能查 `import_job.preview` / `import_job.confirm`。
11. 确认导入 UI 明确提示不能回滚。
12. `external_project_site` 无法看到 Excel 导入。

## 如何在审计日志中查操作人

1. 进入 **系统设置 › 审计日志**
2. 按操作类型筛选 `import_job.preview` 或 `import_job.confirm`
3. 可查看预检时间、确认时间和操作用户

---

## 回滚策略

> **当前系统不支持导入回滚。**

如导入出错：

1. 到对应业务模块（如往来方台账、物料台账）手动停用或作废错误记录
2. 对于健康证等证照，可在证照管理中手动删除错误记录
3. 未来如需批量 rollback，需单独设计回滚接口（目前不在计划内）

如不确定是否导错，优先不操作，联系系统管理员查阅审计日志确认。
