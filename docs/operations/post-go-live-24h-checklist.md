# Post Go-live 24h Checklist

本清单用于公司内网正式上线后 24 小时内复核。正式上线仍指公司内网运行，不代表公网访问；继续保持不公网暴露 API/PostgreSQL。

复核证据保存到 Git 外目录后运行：

```bash
npm run production:post-go-live-24h-check -- --evidence-dir <outside-git-path>/post-go-live-24h
```

## 登录检查

| 角色 | 检查步骤 | 预期结果 | 阻断级别 |
| --- | --- | --- | --- |
| admin | 使用正式 admin 账号登录，打开 Dashboard、系统设置、审计日志。 | 能登录；系统设置可见；审计日志可筛选和导出。 | P0 |
| viewer | 使用 viewer 账号登录，打开 Dashboard、项目点、证照、合同。 | 只读可见；看不到保存、确认、上传、停用等 manage 操作。 | P0 |
| external_project_site | 使用外部项目点账号登录。 | 只进入绑定项目点门户；看不到系统设置、Excel 导入、全局附件管理、成本价、采购价、库存金额。 | P0 |

## 数据检查

| 检查项 | 检查步骤 | 预期结果 | 阻断级别 |
| --- | --- | --- | --- |
| 合同风险 | 打开合同风险页，检查已到期和 30 天内到期合同。 | 合同风险数量与上线证据包中的合同复核结果一致。 | P0 |
| 证照健康证 | 打开证照健康证页，分别检查项目点健康证和公司健康证。 | 已过期、临期、正常状态正确；不出现身份证后四位、健康证编号、发证机关必填口径。 | P0 |
| 项目点风险台账 | 打开项目点风险台账和项目点详情。 | 项目点现场人员、健康证、食品经营许可证、雇主责任险、工资表状态可复核。 | P0 |
| 库存流水 | 打开库存流水，抽查期初、入库、出库、调整流水。 | 流水可查；数量、物料、仓库和经办信息可追溯。 | P0 |
| Excel 导入试点复核 | 打开 Excel 导入试点复核 tab。 | 最近导入批次、错误/警告、合同、健康证、库存复核任务可见。 | P1 |

## 审计检查

| 检查项 | 检查步骤 | 预期结果 | 阻断级别 |
| --- | --- | --- | --- |
| 登录日志 | 筛选上线后 admin、viewer、external_project_site 登录动作。 | 登录审计可查，账号和时间准确。 | P0 |
| import_job.preview / import_job.confirm | 筛选导入预检和确认动作。 | 导入审计可查；不包含敏感字段。 | P0 |
| 附件下载 | 下载一条有权限附件并筛选附件读取审计。 | 附件下载审计可查；scope 外附件不可读。 | P0 |
| 库存出入库 | 抽查库存入库/出库动作审计。 | 业务记录与审计记录能互相定位。 | P0 |

## 备份检查

| 检查项 | 检查步骤 | 预期结果 | 阻断级别 |
| --- | --- | --- | --- |
| 当日数据库备份 | 检查当日 PostgreSQL backup 任务输出和 hash。 | 当日数据库备份完成，证据保存在 Git 外。 | P0 |
| 附件快照 | 检查 NAS attachment snapshot 或备份任务。 | 附件快照完成，至少有文件计数或 snapshot 记录。 | P0 |

## 性能检查

| 检查项 | 检查步骤 | 预期结果 | 阻断级别 |
| --- | --- | --- | --- |
| 页面加载是否异常 | 依次打开 Dashboard、项目点、证照、合同、库存、Excel 导入。 | 首屏可用，无明显白屏、无限 loading、控制台致命错误。 | P1 |
| 导入批次页是否可用 | 打开 Excel 导入批次与行级预览。 | 批次列表、批次详情、错误报告下载可用。 | P1 |
| Dashboard 是否可用 | 打开 Dashboard 并检查待办、风险、最近动态。 | 数据可用；不可用时显示明确 error state，不用 0 冒充真实数据。 | P1 |

## 异常处理

- P0 故障立即回滚/停用服务：登录失败、权限越权、数据库不可用、附件鉴权失效、核心数据不可查、备份失败。
- P1 故障当天修复：页面性能异常、导入复核页异常、非核心导出失败、部分报表延迟。
- P2 进入 backlog：文案细节、非核心布局问题、后续优化项。

所有处理记录、截图、日志、修复 commit 和复核结论都必须保存到 Git 外证据目录。
