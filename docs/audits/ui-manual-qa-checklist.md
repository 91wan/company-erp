# UI Manual QA Checklist

本清单用于 NAS 内网试点前的人工 UI 验收。它补充自动化 render、browser 和 quality budget gate，重点确认真实屏幕是否仍保持“一页一个主任务、一个主表或主队列、一个详情抽屉”的减法结构。

结论边界：通过本清单表示可以进入 NAS 内网试点验收；这不是正式合规档案系统全面上线。公网或跨网访问必须另行完成 HTTPS 反代、Secure cookie、Origin/CSRF、附件上传和审计专项验收。禁止公网暴露 API/PostgreSQL。

## 使用方式

- 使用最新 `main` 构建的试点环境，记录 deploy revision。
- 分别用 `admin`、`viewer`、`project_site`、`external_project_site` 登录检查。
- 先检查 1366px 桌面，再检查 1024px 平板宽度。
- 每项记录实际结果、截图编号、阻断判断和整改负责人。
- 不把 `.env`、secret、DB dump、附件原文、真实业务数据提交到 Git。

## 角色视角

| 检查项 | 检查步骤 | 预期结果 | 是否阻断上线 |
| --- | --- | --- | --- |
| admin 总部驾驶舱 | 使用 `admin` 登录，打开 Dashboard。 | 首屏只出现指标卡、待办队列、风险队列、最近动态和快捷入口；指标来自 summary，数据不可用时显示错误状态，不用 0 冒充真实数据。 | 是 |
| admin 项目点风险 | 进入项目点 workspace。 | 默认打开项目点风险台账，只看到一个主表；不同时显示物料领用、厨房设备、投入合同表。红色风险使用 danger/red。 | 是 |
| viewer 只读 | 使用 `viewer` 登录，依次打开项目点、采购、证照、库存、合同。 | 可以查看列表和详情抽屉；看不到新增、保存、审核、出库、上传等管理动作。 | 是 |
| project_site scope | 使用 `project_site` 登录，打开项目点和物料领用相关页面。 | 只看到 scoped 项目点相关数据；看不到其他项目点、成本价、采购价、库存金额或总部系统设置。 | 是 |
| external_project_site 门户 | 使用 `external_project_site` 登录。 | 只进入外部项目点门户，首屏为任务卡；不出现完整总部导航、系统设置、全局附件管理、成本价、采购价、库存金额或 Storage Key。 | 是 |
| external_project_site section | 在外部项目点门户点击物料领用、项目点现场人员/健康证、食品经营许可证、雇主责任险、工资表。 | 每个入口进入对应 section；不能选择项目点；没有真实明细或动作时显示明确 empty state，不显示假按钮。 | 是 |

## 视口与密度

| 检查项 | 检查步骤 | 预期结果 | 是否阻断上线 |
| --- | --- | --- | --- |
| 1366px 桌面 | 设置浏览器为 1366px x 768px，打开 Dashboard、项目点、采购、证照、库存、合同。 | 主内容不发生横向 document overflow；每个 workspace 默认只显示一个 active tab 内容。 | 是 |
| 1024px 平板 | 设置浏览器为 1024px x 768px，重复主要路径。 | Summary cards 自动换行；表格仍可读；drawer 宽度适配，不遮挡关键操作。 | 是 |
| 表格密度 | 检查项目点风险台账、采购待办、证照风险、库存风险和合同风险主表。 | 主表默认不超过 7 列；长字段、附件、审计、备注在 DetailDrawer 中查看。 | 是 |
| 主操作唯一性 | 检查每个 active tab 顶部操作区。 | 最多一个蓝色 primary action；次要操作为 outline/ghost；危险操作有二次确认。 | 是 |
| 后续开放噪音 | 浏览主要 workspace 首屏和 tab。 | 主界面不出现 disabled 的“后续开放”按钮；未开放内容只在 empty state 中小字说明。 | 否，若占据主操作区则是 |

## 业务流程

| 检查项 | 检查步骤 | 预期结果 | 是否阻断上线 |
| --- | --- | --- | --- |
| 项目点风险 | 打开项目点风险台账，点击第一条项目点。 | 打开 ProjectSiteDetailDrawer；完整 checklist 展示项目点现场人员、健康证、食品经营许可证、雇主责任险、工资表、附件和备注。 | 是 |
| 物料领用 | 打开项目点 > 物料领用。 | 只显示领用队列和相关操作；新增领用在 drawer 中完成；总部出库需二次确认；外部项目点账号不能执行总部出库。 | 是 |
| 厨房设备 | 打开项目点 > 厨房设备。 | 只显示设备和变更队列；总部可新增正式设备；外部项目点账号只可按权限上报变更。 | 是 |
| 采购待办 | 打开采购 workspace。 | 默认是待办 tab，只显示待审批、待采购、异常或被驳回；采购需求和采购执行不与待办同屏堆叠。 | 是 |
| 证照风险 | 打开证照资质 workspace。 | 默认是风险或待审核入口；健康证围绕项目点现场人员匹配展示；食品经营许可证围绕项目点状态展示。 | 是 |
| 库存风险 | 打开库存 workspace。 | 默认展示库存风险或当前 active tab；入库、出库、调整表单不常驻挤占主表。所有物料数量按整数输入和展示。 | 是 |
| 合同风险 | 打开合同 workspace。 | 默认展示合同风险；长金额、附件、审计和备注不塞进主表，进入详情抽屉查看。 | 是 |

## 附件访问

| 检查项 | 检查步骤 | 预期结果 | 是否阻断上线 |
| --- | --- | --- | --- |
| 统一附件入口 | 在合同、证照、项目点详情中查看统一附件。 | 业务页面以附件引用、查看附件、登记附件为主；legacy path 只显示为旧路径字段或迁移参考，不作为下载入口。 | 是 |
| 附件 scope | 使用 `project_site` 和 `external_project_site` 查看附件。 | 只看到绑定项目点 scope 内的 metadata、download-url 和 content；scope 外返回不可见，不泄露存在性。 | 是 |
| 外部项目点附件 | 使用 `external_project_site` 进入健康证、食品经营许可证、雇主责任险、工资表 section。 | 只能通过业务对象受控入口提交或等待总部登记附件引用；不能进入全局附件管理，不能填写 owner、Storage Key 或 raw path。 | 是 |
| 下载错误 | 尝试打开不存在或无权限附件。 | 显示明确中文错误；不展示 NAS 根路径、本机路径、secret 或 storage root。 | 是 |

## 审计日志

| 检查项 | 检查步骤 | 预期结果 | 是否阻断上线 |
| --- | --- | --- | --- |
| 审计日志可见性 | 使用 `admin` 打开系统设置 > 审计日志。 | 可按 action、entityType、actorUsername、date range 筛选；可导出 CSV 并记录 SHA256、筛选条件、导出人和 deploy revision。 | 是 |
| 非 admin 审计隔离 | 使用 `viewer`、`project_site`、`external_project_site` 尝试访问审计日志。 | 不显示审计日志入口；直接访问受权限限制。 | 是 |
| 写操作追责 | 执行一条试点允许的写操作，例如新增领用申请或证照提交。 | 对应业务 mutation 写入审计；审计 JSON 不包含 password、cookie、完整身份证、raw server path。 | 是 |

## NAS 试点前 UI 检查

| 检查项 | 检查步骤 | 预期结果 | 是否阻断上线 |
| --- | --- | --- | --- |
| 证据链命令 | 按 operator runbook 执行 preflight、pilot evidence、audit export verifier、legacy attachment report。 | 所有输出保存在 Git 仓库外；manifest 和 SHA256 可复核。 | 是 |
| 部署边界提示 | 检查部署文档、runbook 和 UI 管理页。 | 明确禁止公网暴露 API/PostgreSQL；跨网访问必须另走 HTTPS、Secure cookie、Origin/CSRF、审计和附件专项验收。 | 是 |
| 试点状态说明 | 在交付记录中写入当前结论。 | 说明“可进入 NAS 内网试点，但不是正式合规档案系统全面上线”；列出历史附件迁移、长期归档制度、恢复演练记录和业务方验收作为正式上线前条件。 | 是 |
| 敏感信息复查 | 检查截图、导出文件、证据目录和 Git diff。 | 不包含 `.env`、secret、DB dump、附件原文、真实业务数据、真实附件路径。 | 是 |
