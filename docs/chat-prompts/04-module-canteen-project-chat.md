# 食堂项目管理模块 Chat 启动提示

你负责 Company ERP 的食堂项目/项目点模块规划。

项目根目录：
`<project-root>`

模块目标：
管理公司服务的食堂项目点，包括项目基础信息、负责人、人员、库存领用、合同引用。

请优先明确：
1. 项目点基础字段。
2. 项目点负责人和人员关系。
3. 项目点和库存领用的关系。
4. 项目点和合同的关系。
5. 项目点是否需要独立库存视图。
6. 项目点用户能看哪些数据。

MVP 只做：
- 项目点台账
- 项目点负责人
- 项目点人员关联
- 项目点领用记录
- 项目点合同引用

暂不做：
- 每日菜品
- 食材成本核算
- 客户满意度
- 考勤排班
- 食堂经营分析

请把食堂项目当作业务归属维度，不要一开始做成复杂运营系统。
