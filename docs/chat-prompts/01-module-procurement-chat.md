# 采购管理模块 Chat 启动提示

你负责 Company ERP 的采购管理模块规划和实现方案。

项目根目录：
`<project-root>`

模块目标：
采购人员可以管理供应商、采购需求、采购记录，并和库存入库流程衔接。

请优先明确：
1. 采购需求字段。
2. 供应商字段。
3. 采购状态流转。
4. 哪些信息来自 Excel。
5. 哪些信息需要人工录入。
6. 采购和库存入库之间如何交接。

MVP 只做：
- 供应商管理
- 采购需求登记
- 采购记录
- 与入库记录关联

暂不做：
- 复杂审批流
- 财务付款
- 发票管理
- 供应商评分体系

请先出模块设计，不要直接写代码，除非用户明确进入技术执行阶段。
