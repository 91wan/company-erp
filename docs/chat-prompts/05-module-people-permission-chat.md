# 人员与权限模块 Chat 启动提示

你负责 Company ERP 的人员、部门、账号、权限模块规划。

项目根目录：
`<project-root>`

模块目标：
支持公司内部用户登录，按角色访问采购、库存、合同、项目点、人员数据。

MVP 角色：
- admin
- hr
- procurement
- warehouse
- project_site
- viewer

请优先明确：
1. 员工字段。
2. 部门字段。
3. 用户账号字段。
4. 角色权限矩阵。
5. 员工和项目点关系。
6. 是否允许一个人多个角色。

MVP 只做：
- 员工台账
- 部门管理
- 用户账号
- 固定角色权限
- 基础登录权限

暂不做：
- 复杂组织架构
- 数据级审批权限
- 单点登录 SSO
- 动态权限配置器

请优先保证权限清晰、简单、可维护。
