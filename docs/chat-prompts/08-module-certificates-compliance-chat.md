# 证照与合规到期管理模块 Chat 启动提示

你负责 Company ERP 的证照、证书、许可证和合规到期管理模块规划。

项目根目录：
`<project-root>`

模块目标：
管理公司运营中需要持续跟踪有效期的证照和合规文件，减少人员健康证、食品许可证、供应商资质、项目点证照等过期风险。

请优先明确：
1. 需要管理哪些证照类型。
2. 每类证照归属对象：人员、项目点、供应商、公司、合同或其他。
3. 证照基础字段。
4. 到期提醒规则。
5. 附件/扫描件如何保存。
6. 谁负责更新，谁负责确认。
7. 证照状态如何计算和展示。
8. 哪些数据来自 Excel，哪些需要人工录入。

MVP 只做：
- 证照台账
- 归属对象：人员、项目点、供应商、公司
- 证照类型
- 证照编号
- 发证日期
- 到期日期
- 提前提醒天数
- 附件路径
- 负责人
- 状态：有效、即将到期、已过期、已停用
- 备注

重点证照类型：
- 人员健康证
- 食品经营许可证
- 营业执照
- 项目点/食堂点相关许可证
- 供应商资质证书
- 合同相关资质文件

暂不做：
- 复杂审批流
- 自动 OCR 识别证照
- 外部政府平台自动核验
- 短信/微信自动提醒
- 法务合规全流程

权限建议：
- HR 可维护人员健康证。
- 项目点负责人可查看本项目点证照状态。
- 采购可查看供应商资质状态。
- Admin 可维护全部证照。
- Viewer 只读查看允许范围内的到期状态。

提醒规则建议：
- 默认提前 30 天提醒。
- 食品经营许可证、营业执照等关键证照可提前 60 或 90 天提醒。
- 到期日期小于当前日期时自动标记为已过期。
- 即将到期和已过期证照应出现在 dashboard 摘要中。

请先产出模块设计、字段建议、状态规则和提醒规则，不要直接写代码，除非用户明确进入技术执行阶段。
